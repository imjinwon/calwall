개인정보 처리방침

시행일: 2026년 11월 18일

1. 처리하는 정보와 이용 목적

CalWall은 사용자가 Google 로그인으로 허용한 범위 안에서 다음 정보를 처리합니다.

  • 캘린더 목록 및 일정 (제목, 시작·종료 시각, 장소, 알림, 반복 설정): 달력, 다가오는 일정, 일정 알림, 일정 찾기에 표시합니다.
  • 일정 추가·수정·삭제: 사용자가 CalWall에서 직접 저장하거나 삭제한 일정만 Google 캘린더에 반영합니다. 대상은 사용자 본인의 캘린더입니다.
  • Google Tasks (제목, 기한, 완료 여부, 메모): 달력에 표시하며, 사용자가 완료 처리하거나 저장한 내용만 반영합니다.

위 정보는 이 기능에만 사용합니다. 광고에 사용하지 않으며, 판매하거나 제3자에게 제공하지 않습니다. 개발자를 포함해 사람이 열람하지 않습니다.

2. 저장 위치

  • 로그인 정보(액세스 토큰), 받은 일정과 할 일, Google 계정 없이 만든 PC 일정은 사용자 PC의 %LOCALAPPDATA%\CalWall 폴더에만 저장합니다.
  • 저장한 데이터는 Windows 데이터 보호(DPAPI)로 암호화하며, 같은 PC의 같은 Windows 사용자만 읽을 수 있습니다.
  • CalWall은 일정을 수집하는 서버를 운영하지 않습니다. 일정과 할 일은 사용자 PC와 Google 사이에서만 전송됩니다.
  • 프로그램 기록(로그)에는 일정 제목을 남기지 않습니다.

3. 개발자에게 전송되는 정보 (선택)

  • 오류 보고: 사용자가 동의한 경우에만 전송합니다. 오류가 발생하면 프로그램 버전, Windows 버전, 오류 내용, 직전 기록 30줄, 익명 설치 번호를 개발자의 Google 스프레드시트로 보냅니다. 이메일 주소, 사용자 폴더 경로, 토큰은 지운 뒤 보내며 일정과 할 일 내용은 보내지 않습니다.
  • 업데이트 확인: 새 버전을 확인할 때 현재 버전 번호만 보냅니다.
  • 두 기능은 설정에서 언제든 끌 수 있습니다.

4. 삭제 및 연결 해제

  • 설정의 [로그아웃]을 누르거나 CalWall을 제거하면 PC에 저장된 로그인 정보와 일정이 삭제되고, Google에 접근 권한 해제를 요청합니다.
  • Google 계정 > 서드 파티 연결에서 CalWall의 접근 권한을 직접 해제할 수도 있습니다.

5. Google API 서비스 사용자 데이터 정책

CalWall이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

Privacy Policy

Effective: November 18, 2026

Google user data. With your permission, CalWall reads your calendar list and events (title, start and end time, location, reminders, recurrence) and your Google Tasks (title, due date, completion, notes) to show them in the calendar, agenda, reminders and search. It creates, changes or deletes events and tasks only when you save or delete them in CalWall. This data is used only for these features. It is not used for advertising, not sold or shared with third parties, and not read by people.

Storage. Sign-in tokens, downloaded events and tasks, and events you keep on your PC without a Google account are stored only in %LOCALAPPDATA%\CalWall, encrypted with Windows DPAPI. CalWall runs no server that collects your events, and event titles are not written to its log.

Optional data sent to the developer. Error reports, only if you opt in: version, Windows version, error text, the last 30 log lines and an anonymous install ID, with email addresses, user folder paths and tokens removed and no event or task content. Update checks send only the version number. Both can be turned off in settings.

Deletion. Sign out in settings or uninstall CalWall to delete local data and request token revocation. You can also remove access at Google Account > Third-party connections.

CalWall's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
